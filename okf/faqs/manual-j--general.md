# what is manual j

Manual J is the ACCA standard for calculating residential heating and cooling loads on a room-by-room basis, producing a BTU/hour output that determines the exact HVAC system size a home requires. Manual J replaces rule-of-thumb sizing methods and is required by Florida Building Code for new installations and replacements. Poulin Cooling A/C and Refrigeration performs Manual J calculations for Clearwater homeowners before any new system installation or replacement.
